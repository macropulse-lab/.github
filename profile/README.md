# MacroPulse

**Know the macro regime before the market does — and prove every decision your agents make.**

Two products, one platform: a daily macro-regime signal for quant teams, and a
cryptographic pre-execution compliance layer for autonomous trading agents.

[Website](https://macropulse.live) · [API Docs](https://macropulse.live/api-docs) · [IRL Engine](https://macropulse.live/irl) · [Track Record](https://macropulse.live/track-record) · [Live Sandbox](https://irl.macropulse.live)

</div>

---

### 🟢 MacroPulse — Macro Regime API
Four regimes (Expansion · Recovery · Tightening · Risk-Off) from Fed liquidity, credit spreads,
volatility, and the yield curve — served over REST, signed with Ed25519, verifiable by anyone.
Free tier available. `pip install macropulse-mcp` to use it inside any AI agent.

### 🟡 IRL Engine — Immutable Reasoning Log
Seals an AI agent's reasoning **before** any order reaches the exchange (SHA-256 / RFC 8785),
writes it to a bitemporal ledger, and anchors daily to Bitcoin — a tamper-evident audit trail
**anyone can verify offline, without trusting us.** [Try the sandbox →](https://irl.macropulse.live)
